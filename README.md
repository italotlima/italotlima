## 🔧 O que a produção me ensinou

* **Nenhum sistema é seguro. Todo sistema é falho:** _A diferença é só quem acha a falha primeiro e o que faz com ela._
* **Pessoas também são hackeáveis:** _Quase sempre são a porta mais barata de arrombar. Isso vale pra defesa e pra venda._
* **Software não é só código:** _Aprendi a lidar com gente antes de aprender arquitetura. As duas coisas quebram do mesmo jeito: no ponto que ninguém monitorava._
* **Escalar não é aumentar CPU e memória:** _Já tentei. Se fosse isso, não existiria engenharia, existiria fatura da cloud._
* **Nunca subestime a criatividade do usuário:** _Todo caminho que você jurou que ninguém ia clicar, alguém clica. Na sexta, às 18h._
* **Cliente chato é o melhor cliente que existe:** _Ele te entrega de graça o roadmap que você pagaria caro pra descobrir. Se você souber escutar em vez de se defender._
* **Com cliente real pagando, sintaxe não basta:** _Tive que descer no event loop, no que é compilado em C por baixo, no protocolo na mão. Quando escala de verdade, você precisa conhecer o core da linguagem, da rede, do banco, de tudo._
* **A melhor linguagem de programação é a que paga as contas:** _O resto é discussão de timeline._
